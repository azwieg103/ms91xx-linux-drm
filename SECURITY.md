# Security Policy

## Supported versions

Security fixes are generally applied to the latest code on the `main` branch and the latest published release. Older releases may not receive security updates.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** feature on this repository (the private vulnerability reporting / security advisory workflow) to send the maintainers a private report. Include the affected version or commit, steps to reproduce, impact, and any proof-of-concept needed to validate the issue.

If private vulnerability reporting is unavailable, contact the repository owner privately through GitHub before disclosing details publicly.

Please allow a reasonable period for investigation and remediation before public disclosure.

## Scope

Reports involving this repository's source code, build workflows, release artifacts, or packaging are in scope. Do not test against systems or services you do not own or have explicit permission to assess.
