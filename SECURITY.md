# Security Policy

## Supported version

Security fixes are prioritized for the latest published release. Users should upgrade to the latest supported release where practical.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue or pull request.

Use GitHub's **Report a vulnerability** feature on this repository to submit a private vulnerability report. Include:

- A concise description and potential impact.
- Affected versions, distributions, and kernel versions.
- Steps to reproduce or a proof of concept, if safe to share.
- Any suggested mitigation.

If GitHub's private vulnerability reporting option is unavailable, contact the maintainer privately through the contact information on the maintainer's GitHub profile and ask for a secure reporting channel. Do not send credentials, private keys, or unrelated personal information.

The maintainer will acknowledge reports as soon as reasonably practical, investigate, and coordinate a fix and disclosure. Please allow time for a fix before public disclosure.

## Scope

This project includes Linux kernel driver code, DKMS packaging, installation/removal scripts, and release automation. Reports concerning any of these components are welcome.
